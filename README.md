# Nec Book Stack

A multi-app digital book platform that combines a TypeScript backend API, a React Native mobile application, and a Python desktop application.

## Overview

Nec Book Stack is a portfolio full-stack product built around a digital book ecosystem. The repository contains three related applications that work across backend, mobile, and desktop environments.

This project reflects practical multi-app architecture, API-driven workflows, authentication handling, content and purchase flows, and cross-platform product development.

## Applications

- `nec-book` — backend API built with TypeScript and Node.js
- `nec-book-app` — mobile application built with React Native and TypeScript
- `nec-book-desktop-app` — desktop application built with Python

## Features

- authentication and user account flows
- book listing and detail handling
- order and subscription workflows
- transaction-related backend structure
- mobile reading and purchase-related screens
- desktop-side operational utilities and user management
- multi-app product organization in a single repository
